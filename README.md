# 📒 오늘의 일기 도우미

특수교육 학생이 날짜·날씨를 고르고, 누가/언제/어디서/무엇을/어떻게/기분을 고르거나 써서 일기를 완성하도록 돕는 웹앱입니다.

## 파일
- `index.html` : 앱 전체 (별도 설치 없음)
- `Code.gs` : 구글 시트 저장용 Apps Script

## 실행
1. 저장소 `baesaeha-source/diary`에 `index.html`, `Code.gs`, `README.md`를 올립니다.
2. GitHub 저장소 → Settings → Pages → Branch `main` / `(root)` 선택 → Save
3. 잠시 후 `https://baesaeha-source.github.io/diary/` 로 접속합니다. (스마트폰·태블릿 가능)

## 구글 시트 + AI 코치 연결
1. 새 구글 시트를 만듭니다. (`일기` 탭은 자동 생성: A=날짜, B=날씨, C=내가 쓴 글, D=AI가 수정해준 글)
   - 예전 버전으로 만든 시트가 있으면 D1 칸에 `AI가 수정해준 글`을 써 주세요.
2. 시트 메뉴 → 확장 프로그램 → Apps Script → `Code.gs` 내용을 붙여 넣고 저장
3. Apps Script 왼쪽 ⚙️ 프로젝트 설정 → **스크립트 속성**에 2개를 추가합니다.
   - `ANTHROPIC_API_KEY` : Anthropic 콘솔에서 발급한 API 키 (앱 화면·GitHub에는 절대 넣지 않습니다)
   - `ACCESS_CODE` : 선생님이 정한 비밀번호 (다른 사람이 주소를 알아도 AI를 못 쓰게 막아 줍니다)
4. 배포 → 새 배포 → 유형 `웹 앱` → 실행 계정 `나` / 액세스 `모든 사용자` → 배포 후 권한 허용
5. 나온 `.../exec` 주소와 3번의 비밀번호를 앱 하단 "선생님 설정"에 붙여 넣습니다. (기기별 1회)
   - `Code.gs`를 고친 뒤에는 "배포 관리 → 새 버전"으로 다시 배포해야 반영됩니다.

## 참고
- AI 코치를 쓰면 학생 일기 글이 Anthropic API로 전송됩니다. 학교·기관의 개인정보 지침을 확인하고, 실명 등은 쓰지 않도록 지도해 주세요.
- AI 사용에는 API 비용이 들 수 있습니다.
- "내가 쓴 글"의 맞춤법 보정은 **규칙(사전) 기반**이라 자주 틀리는 표현만 고칩니다. 목록은 `index.html`의 `FIXES`에 추가하세요.
- 학생 표현을 바꾸지 않도록 어휘는 고치지 않고, 오타·마침표·공백만 다듬습니다.
- 모든 글은 브라우저 안에서만 처리되며, 저장 버튼을 눌러야 시트로 전송됩니다.
